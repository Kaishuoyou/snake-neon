# 🐍 Snake Neon

> 深夜霓虹風格的網頁版貪吃蛇遊戲，融合毛玻璃設計、雙色光球動態背景與完整的遊戲數據記錄系統。

---

## ✨ 功能特色

### 🎮 遊戲玩法
- 經典貪吃蛇核心機制：吃食物、躲牆壁、避免咬到自己
- **10 級速度系統**：每吃 5 個食物自動升一級，最高速達 60ms/幀
- **蛇眼細節**：頭部有方向感知的眼睛，隨移動方向轉動
- **食物動效**：金色食物帶有脈衝縮放與光暈發光效果
- **死亡震盪**：碰撞瞬間畫布產生紅色爆閃 + 0.55 秒震盪動畫

### 🔐 遊客登入
- 遊戲啟動前顯示登入面板，輸入 1–12 字元暱稱
- LocalStorage 記憶上次暱稱，下次自動填入
- 歷史玩家會顯示最高分與遊玩次數預覽
- 遊戲中可隨時「切換玩家」返回登入頁

### 📊 數據記錄
每局結束自動記錄並存至瀏覽器 LocalStorage：

| 欄位 | 說明 |
|---|---|
| 分數 | 本局最終得分 |
| 等級 | 達到的最高速度等級 |
| 遊戲時長 | 從開始到結束的秒數 |
| 登入時間 | 本次遊玩的登入時間點 |
| 日期 | 遊玩日期 |

### 🏆 排行榜
- 顯示目前玩家最近 **10 局**記錄
- 最高分局次以金色高亮標示 🥇
- 即時顯示累計遊玩局數與總時長
- 支援一鍵清除個人記錄

## 🚀 快速上手

無需安裝任何套件，直接用瀏覽器開啟即可：

```
雙擊 index.html 或在瀏覽器中開啟：
file:///path/to/snake-game/index.html
```

**建議瀏覽器**：Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+

## 📁 檔案結構

```
snake-game/
├── index.html    # 頁面結構（登入面板 + 遊戲介面）
├── style.css     # 全域樣式與設計系統
├── game.js       # 遊戲邏輯、渲染引擎、數據記錄
└── README.md     # 本文件
```

### 模組職責

**`index.html`**
- 登入畫面（`#login-screen`）
- 遊戲畫面（`#game-screen`）：左側面板、Canvas、右側排行榜
- 分數飛出動畫容器（`#score-pop-container`）

**`style.css`**
- CSS 設計 Token（`--color-*`、`--glow-*`、`--radius-*`）
- 動態背景球體動畫（`@keyframes floatBlob1/2`）
- 毛玻璃卡片、霓虹按鈕、排行榜樣式
- 死亡震盪動畫（`@keyframes screenShake`）
- 響應式佈局（`@media max-width: 780px`）

**`game.js`**
- 常數配置（格子大小、速度、升級閾值）
- 遊戲狀態物件（`state`）
- LocalStorage 讀寫（按玩家暱稱分區儲存）
- Canvas 渲染：格線、蛇體漸層、食物脈衝、蛇眼
- 鍵盤事件（`e.code`）與觸控滑動事件
- 登入流程、排行榜更新、分數飛出動畫

## ⚙️ 技術架構

```
純前端 · 零依賴 · 無需建置工具
─────────────────────────────────
HTML5 Canvas API    → 遊戲畫面渲染
Vanilla JavaScript  → 遊戲邏輯（ES6+）
Vanilla CSS         → 樣式與動畫
LocalStorage API    → 數據持久化
Google Fonts CDN    → Outfit 字體（需聯網）
```

### LocalStorage 數據格式

每位玩家的數據以 `snakeNeonData_<暱稱>` 為 key 存儲：

```json
{
  "highScore": 150,
  "totalGames": 12,
  "totalTimeSec": 3600,
  "records": [
    {
      "score": 150,
      "level": 6,
      "durationSec": 240,
      "date": "07/25",
      "loginTime": "07/25 10:44"
    }
  ]
}
```
